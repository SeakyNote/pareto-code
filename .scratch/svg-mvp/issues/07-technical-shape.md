# 选择满足本机交付的最简技术方案

Type: grilling
Labels: wayfinder:grilling
Status: open
Parent: ../map.md
Blocked by: 04, 06

## Question

在手工整理数据、本机浏览器运行和 20 小时预算下，静态应用加数据文件是否足够，还是确有需要独立后端的能力？

需决定技术栈、数据更新方式、本机启动与演示方式，以及计算和数据校验放置位置。若选择后端，应指出它满足哪个已确认需求以及增加的投入；方案中“暂定 B/S”不是必须建设前后端服务的结论。

优先选择能满足已确认交互和数据契约的最小方案，不预先建设扩展框架。

## Dependencies

以[数据契约](04-comparability.md)和[最小交互](06-interaction.md)约束技术选择。
