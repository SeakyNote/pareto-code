什么是帕累托前沿？

如果不存在另一配置，在效果不低、费用不高、耗时不长的同时，至少有一项严格更好，那么这个配置就在前沿上。

效果 ↑   费用 ↓   完整执行耗时 ↓

三项指标完全相同的配置互不支配。前沿提供多种各有优势的选择，不将所有配置压缩成一个总分榜单。

页面圆环表示三目标前沿；虚线是二维投影包络。某配置可能因为更快而位于三目标前沿，即使它没有出现在费用与效果的二维包络上。

只比较同口径数据

每个快照独立记录场景、任务集、评分规则、模型版本、Agent、推理强度、渠道、来源和评测时间。系统只在同一快照、同一渠道内开展比较。

评分上限由数据定义，不是所有模型通用的“智力值”。所有任务（包括失败任务）计入每任务均值；耗时必须从任务发起统计到返回完整结果。

缺少效果、费用、完整耗时或样本数量，以及统计口径未对齐的记录，会列为“待补齐”，不会参与前沿或推荐。超过 30 天的快照会提示复测。

API 与订阅如何计费？

API 渠道使用同一批任务的平均调用费用。USD 与 CNY 各自按快照币种展示，系统不隐式换汇。

订阅均摊费用 = 月订阅费 ÷ 月有效任务量

订阅月费和任务量均由用户输入，是计划假设。均摊费用不等于一次任务的新增支出，也不保证会员限额、排队或超额费用。两个渠道分别计算前沿，不互相支配。

初始月费 20、任务量 400 仅是演示输入，不是任何会员方案的官方报价。

推荐为什么选择它？

推荐首先满足预算、耗时、最低效果条件，再从三目标前沿中选择。经济档取最低费用，效果档取最高效果，同价或同分时使用确定性规则打破平局。

偏好推荐对满足条件的前沿配置进行区间归一化，默认效果、费用、速度权重为 50%、25%、25%。效果优先为 80/10/10，节省费用为 25/65/10，更快完成为 25/10/65。

偏好权重不改变前沿。没有满足条件的配置时，系统明确给出空结果和需要放宽的条件；同一配置可以出现在多个推荐档位。
