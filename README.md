# Pareto Code

根据 [`方案/AI应用大赛参赛方案介绍.md`](方案/AI应用大赛参赛方案介绍.md) 实现的 AI 应用效费比评估与智能选型 MVP。围绕**代码开发**打通“评测数据 → 预算与耗时约束 → 三目标帕累托筛选 → 配置对比与推荐 → 导出报告”的闭环。

当前内置快照为**人工构造的演示数据**，不是从截图还原的实测结果，不代表真实模型能力或官方价格。无需 API Key；不会产生模型调用费用。

## 启动

需要 **Node.js 22.13 或更新版本**（使用内置 `node:sqlite`）。运行时没有第三方依赖，无需 `npm install`。

```bash
npm start
```

打开 **http://127.0.0.1:3000**。首次启动自动创建 `.data/pareto.sqlite` 并载入演示快照。Node.js 22/24 可能提示 SQLite 为实验性功能，不影响启动。

```bash
npm run dev       # 修改服务端后自动重启；前端修改后刷新页面
npm run check     # JavaScript 语法检查
npm test          # 算法、导入、数据库持久化和 HTTP 集成测试
```

可复制 `.env.example` 为 `.env` 调整 `HOST`、`PORT`、`DATABASE_PATH`。开发机默认监听回环地址；在公司内网试用时可设置 `HOST=0.0.0.0`。此 MVP 是受信任环境中的共享工作区，尚无账号和权限隔离。

## 体验路径

1. 在“选型工作台”选择代码开发和评测快照，填写每任务预算、完整执行耗时上限及最低效果，点击“生成选型建议”。留空预算或耗时表示不限；`0` 预算按零预算处理。
2. 查看费用 / 效果或耗时 / 效果散点图。圆环是**效果、费用、耗时三目标前沿**；虚线是当前两个维度的投影包络，两者含义不同。支持线性 / 对数坐标、仅看前沿、悬停详情和键盘操作。
3. 查看经济、偏好、效果三个推荐档位及依据。点击图中配置或表格对比按钮，可固定最多 5 个配置，刷新后保留选择。没有满足条件的配置时，展示空结果和违反的条件，绝不自动放宽需求。
4. 切换“GPT 会员折算”，输入假设月费和月有效任务量。系统按“月费 ÷ 有效任务量”均摊费用，**与 API 渠道分别计算前沿**。初始 20 / 400 只是演示假设。
5. 点击“导出报告”，下载包含条件、推荐、前沿、来源、快照时间与费用假设的 Markdown 文件。已修改但未重新分析的条件不能导出为旧报告。

## 接入实测数据

在“导入评测”下载 JSON 或 CSV 模板，或参考 [JSON 示例](examples/benchmark-template.json) 和 [数据格式说明](docs/data-format.md)。

- 替换任务集、评分规则、来源、日期与模型测量值；实测数据将 `source.type` 改为 `internal`，第三方数据改为 `third-party` 并填写来源链接。
- 先“校验并预览”，再“确认导入”；预览不写入数据库。JSON、CSV 均支持多个独立快照。
- 导入按事务整体保存，不覆盖已有快照；同 id 的新评测应改用新快照 id。
- 指标缺失使用 `null`（CSV 留空）。缺失或口径不符的数据保留展示，但不进入帕累托和推荐。
- SVG、办公自动化、文档编写与审查已具备场景入口；导入对应场景快照后自动启用，无需修改代码。
- 可在“评测数据”查看来源与历史，导出原始 JSON。备份 `.data/` 前请先停止服务，或使用 SQLite 一致性备份工具，避免遗漏 WAL 中的写入。

系统根据导入者声明的元数据隔离可比范围，不会验证第三方数据的真实性或自动证明两个评测标准等价。

## 浏览器验证

浏览器检查需要可用的 Playwright 和 Chromium，**不影响应用正常启动**：

```bash
npm install --no-save playwright
npx playwright install chromium
npm run test:browser
```

已有系统 Chromium 时自动使用 `/usr/bin/chromium`；也可设置 `BROWSER_EXECUTABLE`。已有 Playwright 时可用 `PLAYWRIGHT_MODULE_PATH` 指向其 `index.mjs`。检查使用独立的内存数据库，不改变本地工作区的评测数据；桌面和手机截图写入已忽略的 `test-results/`。

## 项目结构

```text
public/          无构建步骤的响应式中文界面、SVG 图表与交互
server/          HTTP API、SQLite、校验、三目标算法和报告
tests/           算法、数据导入及 HTTP 集成测试
scripts/         语法检查和浏览器全流程检查
examples/        可导入的 JSON / CSV 演示模板
docs/            MVP 规格、架构决策、数据格式与 API
方案/            原始参赛方案与参考原型
```

实现边界、验收标准见 [MVP 规格](docs/mvp-spec.md)，技术与比较口径决策见 [架构决策](docs/decisions.md)。此版本采用确定性推荐解释，未接入付费模型执行、自建评测自动跑分、AI 主观判分、实时价格抓取或统一身份认证。
