# Triage Labels

本地任务在顶部的 `Status:` 行使用下列状态。

| 技能中的角色 | 本仓库的状态 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 待维护者评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 规格完整，可由代理实现 |
| ready-for-human | ready-for-human | 需要人工实现 |
| wontfix | wontfix | 不予处理 |

技能提及分诊角色时，使用对应状态字符串。
修改状态名称时，更新此表的“本仓库的状态”列。
