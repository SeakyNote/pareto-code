# MVP 规格与验收范围

## 用户目标

使用付费 AI 的员工选择任务场景，在明确预算、完整执行耗时与最低效果后，找到同口径下各有优势的配置，并能检查推荐依据及导出选型结果。

## 已实现

| 能力 | 验收行为 |
| --- | --- |
| 核心场景 | 初始可用代码开发；有数据后启用 SVG、办公和文档场景 |
| 数据接入 | JSON / CSV 模板、文件选择与拖放、粘贴、服务端校验、预览、事务导入 |
| 数据追溯 | 保存来源、日期、测试集、规则、模型版本、Agent、推理强度、供应商与渠道 |
| 可比性 | 每个快照和渠道独立计算；指标缺失或口径不符单列原因 |
| 费用 | API 每任务平均费用；会员按用户的月费与任务量均摊；币种不混用 |
| 约束 | 预算与耗时上限、最低效果；包含边界；空上限表示不限；零预算保留 |
| 数学筛选 | 三目标帕累托、支配示例、可行性判断；偏好不改变前沿 |
| 推荐 | 经济、偏好、效果档位，允许重合；空结果提供违反条件，无隐式放宽 |
| 图表 | 费用 / 效果、耗时 / 效果切换，线性 / 对数，前沿圆环、二维包络、悬停详情 |
| 对比 | 图表或列表添加，最多 5 项；按快照与渠道隔离，浏览器刷新后恢复 |
| 列表 | 搜索、数值排序、前沿 / 可行 / 待补齐过滤、配置来源与推荐依据详情 |
| 导出 | 当前分析报告 Markdown；原始完整快照 JSON |
| 持久化 | SQLite 重启保留快照与历史；重复快照 id 禁止覆盖 |
| 可用性 | 中文响应式页面、手机导航、键盘操作、基本错误提示与过期快照提醒 |

## 首版不包含

自动执行付费评测任务、外部榜单自动抓取、实时价格与汇率、AI 主观评分、多轮 Agent 运行器、账号权限、配额管理或真实节约效果证明。使用方需导入有依据的实测数据，最终选择由人工决定。

## 验证

- 核心算法：三维支配、全等点、顺序不变性、边界、零费用与缺失区别、偏好与前沿独立、订阅隔离与无解情况。
- 导入与数据库：JSON / CSV、引号与换行、字段类型与范围、真实日期、元数据冲突、不可执行来源链接、事务回滚、重启保留。
- HTTP：资源访问、源码与数据库隔离、参数校验、预览不写入、导入冲突、模板、报告、请求大小及跨站写入检查。
- 浏览器：桌面 / 手机布局、导航、图表投影、筛选、排序、搜索、详情、对比上限与恢复、订阅折算、错误导入、跨场景导入、HTML 转义与报告下载。

实际运行结果以 `npm test` 和 `npm run test:browser` 的输出为准；浏览器检查使用临时内存库，截图保存到 `test-results/`。
